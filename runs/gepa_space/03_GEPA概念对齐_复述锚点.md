## 一、开场必答（一句话定位）

**GEPA 属于「黑盒优化 / 进化计算」家族，不是梯度法、不是强化学习。**

复述要求：能说出它和「梯度法 / RL」的本质区别（见 §四），说不出 = 只停在结论。

## 二、5 步循环复述锚点（每步 → ML 对齐）


| 步          | GEPA                 | ML 对齐（一句话锚点）             |
| ---------- | -------------------- | ------------------------ |
| 选 Select   | 从帕累托前沿挑一个候选          | 选择算子 selection           |
| 跑 Execute  | minibatch 上评估，捕获完整轨迹 | 适应度评估 fitness evaluation |
| 反思 Reflect | 反思 LLM 读轨迹诊断「为什么坏」   | GEPA 独有（LLM 生成方向）        |
| 变异 Mutate  | 反思 LLM 生成改进版候选       | 变异算子 mutation（但 LLM 诊断式） |
| 收 Accept   | 变好进池，没变好丢弃           | 精英保留 elitism             |


**卡壳点**：反思和变异是**同一次 LLM 调用**完成的（边读错误边吐改进）——这是它比传统遗传算法聪明的地方，复述时最容易漏。

## 三、三个「必须讲清机制」（考「为什么」层，不是「是什么」）


| #   | 机制               | 复述锚点                                       | 讲不清的表现                      |
| --- | ---------------- | ------------------------------------------ | --------------------------- |
| 1   | ASI = 文本版梯度      | evaluator 返回 error/traceback = 「改哪、怎么改」的方向 | 只说「返回错误信息」，没说「等价于梯度」        |
| 2   | 帕累托前沿 = 非支配集     | 每个子任务冠军都留，不平均掉局部专长                         | 只说「保留多个候选」，没说「为什么不平局」       |
| 3   | 反思变异 = LLM 诊断式变异 | 把 GA 的「随机变异」换成「读错误再改」                      | 只说「LLM 生成候选」，没说「对比随机变异的升级点」 |

## 四、一个「必须区分」的边界（判断是否真懂）

**GEPA ≠ RL/MDP**：

- RL 学 state→action policy，需要环境 + 预标注 reward + 海量交互。
- GEPA 不学 policy，是进化搜索（候选池 + 变异 + 选择），只要一个能打分的 evaluator。

**推论**：你之前担心的「决策链库缺 result 列」——GEPA 根本不需要历史 result，evaluator 每次**现打分 + 现返回 side\_info**，运行时给 reward + 梯度，不用预标注。

## 五、自测题（复述锚点，考试推进时逐题过）

1. GEPA 属于哪一族？和梯度法、RL 的本质区别是什么？

- 属于黑盒算法（进化搜索）梯度是通过loss函数，找到梯度下降决定的参数更新的方向，来做的；RL是reward来确定参数更新的方向；GEPA的参数更新方向是 通过ASI，另外1个LLM给出来的为什么出错的；

1. evaluator 返回什么？这个返回等价于 ML 里的什么？

- evauator返回的是下次迭代的方向包含，哪里错了，为什么错了；返回等价于参数更新的方向；

1. 帕累托前沿为什么「不平局」？它的 ML 等价概念是什么？

- 等价于给定某个问题，给出的模型参数是什么，只是此次参数变成了，提示词空间+模型+任务空间；等价于LLM的 数据+模型+预测label

1. GEPA 对传统遗传算法的**唯一核心升级**是什么？

- ASI : 文本梯度作为反馈信号，能评分，但是无法打标的；用黑盒打败黑盒；

1. 为什么 GEPA 不需要预标注 reward？（联系决策链库缺 result 的解法）

- 不需要标注reward的，因为他的反馈和学习方向是通过另外个LLM来给出的，是更加高层的基于AI Native的优化算法；

**过题标准**：每题都能讲到「底层机制」层（§三/§四），不停在「结论」层。
