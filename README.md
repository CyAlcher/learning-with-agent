# Learning with Agent

> 与 AI 协同学习：把 AI 嵌入 jwasham 的学习流程（清单化 + 间隔重复 + 动手验证），人出方向、AI 出反馈，并监控学习有没有真正对外转化。

## 锚点：jwasham 的学习流程

**jwasham/coding-interview-university**（36 万 ⭐ / 8.5 万 fork，全球第一「公开学习」仓库）

John Washam 自学转岗进 Amazon，他的学习流程四要素：

- **清单化**：列一张分科清单逐个打勾，避免「感觉学了其实没学」
- **间隔重复（Anki）**：把知识点钉进长期记忆，对抗遗忘
- **动手验证**：`Don't just read about it — code it`，读完不算会，写出来才算
- **聚焦**：他复盘 "I wasted a lot of time on things I didn't need to know" → 别贪多

## 与 AI 协同学习（AI 嵌入这三步）

| jwasham 流程 | AI 嵌入后（人 + AI 协同） |
|---|---|
| 清单化 | AI 列清单 + 追踪进度，人逐个打勾 |
| 间隔重复 | AI 出题 + 打分 + 反馈，暴露「停在结论、讲不清机制」 |
| 动手验证 | AI 辅助写代码 + 验证「真会了」 |

## 监控

- **学习过程**：考试评测（AI 出题打分），盯「有没有到转化，不是停在理解概念」
- **对外转化**：每 2 天查对外提交量，0 提交 → 飞书告警「未对外转化」
